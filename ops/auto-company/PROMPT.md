# Neville Goddard SOA Autonomous Execution Loop

Read `ops/auto-company/CHARTER.md` and `ops/auto-company/consensus.md` before doing anything.

For each cycle:
1. Identify the single highest-value executable Next Action.
2. Select only 3-5 of the 14 roles needed.
3. State the measurable KPI expected to move.
4. Execute the work using available tools and repository context.
5. Produce a concrete artifact: code, tested funnel change, verified deployment, outreach asset, analysis tied to a decision, or other measurable deliverable.
6. QA the result. Do not count drafts or intentions as completed execution.
7. Update `consensus.md` with verified evidence, blockers, and exactly one highest-leverage next action.
8. If a founder-only action is required, prepare everything around it so the founder has one minimal action to take.

Forbidden:
- Fabricated revenue, customers, outreach, submissions, traffic, rankings, deployments, or partnerships.
- Committing secrets.
- Unauthorized spending or binding agreements.
- Repeating low-impact busywork.
- Endless discussion without a shipped artifact.

Default optimization order:
CASH -> RECURRING CASH FLOW -> RETENTION -> DISTRIBUTION -> AUTOMATION -> ENTERPRISE VALUE.
